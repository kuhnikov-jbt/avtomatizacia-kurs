== База знаний

# База знаний курса

::: lead
Одна страница, куда можно вернуться из любого урока: что означают слова, сколько что стоит, какие
команды пригодятся и что делать, когда встали. Пополняется по ходу программы, после наших созвонов.
:::

## Слова, которые будут попадаться

| Слово | Что это на самом деле |
| --- | --- |
| Модель | Программа, которая отвечает на ваши запросы. Бывает сильнее и дороже, слабее и дешевле. |
| Клод в браузере | Обычный чат на сайте. Отвечает, но ваших файлов не видит. |
| Claude Code | Программа на вашем компьютере. Видит папку, пишет и запускает код, меняет файлы. |
| Запрос (промпт) | То, что вы пишете. Чем точнее сказано, что нужно и чем проверять, тем меньше переделок. |
| Контекст | Всё, что модель перечитывает перед ответом: ваши файлы, история разговора, файл правил. Чем он больше, тем дороже ответ. |
| Токены | Единицы, в которых считается объём текста. Расход подписки идёт в них, а не в сообщениях. |
| Лимит | Сколько работы доступно за период по вашей подписке. Кончился, значит ждать окна или брать тариф выше. |
| API и ключ | Способ обращаться к модели из своих программ, оплата по расходу. Понадобится в уроке 6, не раньше. |
| Терминал | Окно, где команды пишут словами, а не кликают мышкой. Внутри уроков будет 5-6 команд, не больше. |
| Сервер | Чужой компьютер, который работает круглосуточно. Нужен, чтобы система жила без вашего ноутбука. |
| Cron | Расписание: «делай это каждый час». Так система работает, пока вы спите. |
| CRM | Место, где живут клиенты и сделки. У вас это может быть Битрикс, амо, таблица или тетрадь. |
| Журнал (лог) | Файл, куда программа пишет, что делала. Первое место, куда смотрят, когда что-то не так. |

## Сколько что стоит

Цены на сентябрь 2026 года, проверяйте перед покупкой: они меняются, а курс тем более.

| Что | Цена | Когда покупать |
| --- | --- | --- |
| Claude Pro | 18 € в месяц, 15 € при оплате за год | Урок 0, сразу |
| Claude Max | от 90 € в месяц | Только если упёрлись в лимит, обычно после урока 7 |
| Оплата по API | по расходу, считается за объём текста | Урок 6, когда система начнёт работать сама |
| Простой сервер | 300-700 ₽ в месяц | Урок 5 |
| Доступ (VPN) | 200-600 ₽ в месяц | Урок 0 |
| Домен, если понадобится | 200-1500 ₽ в год | По желанию, ближе к уроку 8 |

::: note Про лимиты по-простому
Лимит расходуется быстрее всего в двух случаях: очень длинный разговор и очень большие файлы,
которые перечитываются на каждом ответе. Если счётчик кончается подозрительно рано, дело почти
всегда в этом, а не в сложности задач.
:::
