# Автоматизация бизнеса с Клодом. Программа обучения

Сайт программы: https://kuhnikov-jbt.github.io/avtomatizacia-kurs/

Учебная программа для предпринимателя: с нуля до собственной системы автоматизации
продаж. 12 уроков, у каждого проверяемый результат. Формат курса взят у обучения
«AI Superpowers» (https://sfer.ai/edu/aisuperpowers3), содержание своё.

Ссылка не публикуется и закрыта от поисковиков: `robots.txt` с `Disallow: /` плюс
`<meta name="robots" content="noindex,nofollow">` на каждой странице. Доступов, ключей
и данных внутри уроков нет.

## Что где лежит

| Что | Где |
| --- | --- |
| Тексты уроков | `_src/lessons/NN-slug.md` |
| Оглавление | `_src/index.md` |
| База знаний | `_src/kb/*.md` |
| Сборщик | `build.py` |
| Готовые страницы | `index.html`, `l/NN-slug.html`, `kb.html` |
| Стиль и шрифты | `assets/style.css`, `assets/fonts/*.woff2` |
| Прогресс и кнопки | `assets/app.js` |
| Кадры экрана | `img/NN/<кадр>.png` |

## Как править

1. Правите markdown в `_src/`.
2. `python3 build.py`: собирает HTML в фирменном стиле.
3. `git add -A && git commit && git push`: GitHub Pages обновляет сайт сам.

Зависимостей нет: нужен только python3 из системы.

## Разметка внутри уроков

Кроме обычного markdown сборщик понимает блоки:

```
::: term Подпись к кадру терминала
$ команда
:::
```

Виды блоков: `term` (кадр терминала), `prompt` (готовый промпт с кнопкой
«скопировать»), `lead` (вводный абзац), `goal` (цель урока), `rake` (грабли),
`note` (врезка), `q` (вопрос-ответ), `report` (кнопка отчёта), `links` (кнопки-ссылки),
`nums` (сетка чисел).

Шапка урока задаётся фронтматтером: `num`, `title`, `goal`, `time`, `status` (`ready` или
`soon`), список `check` (пункты чек-листа: `id | текст`).

Если кадра ещё нет, сборщик ставит на его место честную заглушку «Кадр экрана
готовится», а не рисованный макет.

## Прогресс ученика

Галочки чек-листа и отметки пройденных уроков живут в браузере ученика
(`localStorage`, ключ `kurs-progress`). Сервера нет, наружу ничего не уходит.
Кнопка «Собрать отчёт» на странице урока складывает текст для созвона и копирует
его в буфер.
